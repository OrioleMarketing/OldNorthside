Recommended integration path

Recommended target architecture:
one inventory master

Design rule
Move deliberately from calendar protection to certified distribution—without running two independent inventory authorities.
Stage 1

Stabilize

Preserve the current external calendars while the inn collects the real room mappings and feed URLs.

Control pointPer-room iCal import and export only after a safe mapping review.
Exit criterionEvery room’s external listing and direct-booking calendar is known.
Stage 2

Select & map

Choose eviivo or Beds24, then map seven rooms and rate plans in a test or parallel-run environment.

Control pointTest bookings, changes, cancellations, and exception handling before cutover.
Exit criterionRoom and rate-plan mappings reconcile across all connected channels.
Stage 3

Cut over

Make the selected manager the authoritative inventory hub and activate its certified Expedia connection.

Control pointConnect the direct website through the manager’s supported interface.
Exit criterionRetire the duplicate iCal loop after monitored validation.
Target state
The channel manager owns sellable inventory; Expedia and the direct website consume synchronized availability from that single source.
